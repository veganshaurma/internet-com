Python Разработчик

Full-time Бишкек / Remote
О роли

Разработка backend-компонентов, проектирование сервисов и REST API в рамках проектов заказной разработки. Работа в составе команды, взаимодействие с QA-специалистами и аналитиками.

Обязанности
  • Разработка и поддержка backend-компонентов веб-приложений
  • Проектирование и реализация REST API
  • Работа с реляционными базами данных (PostgreSQL, MySQL)
  • Интеграция со сторонними сервисами и API
  • Участие в код-ревью
  • Взаимодействие с QA-специалистами при тестировании и исправлении дефектов
  • Участие в уточнении требований совместно с аналитиком
Требования
  • Python 3.x — опыт коммерческой разработки от 2 лет
  • Уверенное знание Django или FastAPI
  • Опыт работы с SQL и реляционными СУБД
  • Понимание принципов REST API и HTTP-протокола
  • Опыт работы с Git
  • Умение читать и писать техническую документацию
Будет плюсом
  • Опыт с Docker / Docker Compose
  • Знание брокеров сообщений (RabbitMQ, Kafka)
  • Опыт с микросервисной архитектурой
  • Понимание принципов тестирования ПО
Условия
  • Полная занятость
  • Возможен удалённый формат работы
  • Проектная деятельность с реальными задачами

Frontend Разработчик

Full-time Бишкек / Remote
О роли

Разработка пользовательских интерфейсов для веб-приложений. Работа в тесном взаимодействии с backend-командой и дизайнером, участие в обсуждении требований и демонстрациях заказчику.

Обязанности
  • Разработка адаптивных UI-компонентов на React или Vue.js
  • Интеграция с backend API
  • Обеспечение кросс-браузерной совместимости
  • Оптимизация производительности фронтенда
  • Участие в код-ревью
  • Взаимодействие с QA при тестировании UI
Требования
  • React или Vue.js — опыт коммерческой разработки от 2 лет
  • JavaScript / TypeScript на уверенном уровне
  • HTML5, CSS3, адаптивная вёрстка
  • Опыт работы с REST API
  • Понимание принципов работы браузера и DOM
  • Git
Будет плюсом
  • Опыт работы с Figma
  • Знание Storybook
  • Опыт написания unit-тестов для компонентов
  • Знание инструментов сборки: webpack, Vite
Стек
React / Vue TypeScript HTML/CSS Vite / webpack REST API
Условия
  • Полная занятость
  • Возможен удалённый формат работы

Solution Architect

Full-time Бишкек / Remote
О роли

Проектирование архитектуры программных решений, обеспечение технической целостности проектов. Взаимодействие с командой разработчиков и бизнесом заказчика, участие в стадии discovery и presale.

Обязанности
  • Проектирование архитектуры программных решений
  • Выбор технологического стека и архитектурных паттернов
  • Взаимодействие с бизнесом заказчика для уточнения требований
  • Взаимодействие с командой разработки: постановка задач, ревью решений
  • Подготовка архитектурной документации: схемы компонентов, ADR, C4-диаграммы
  • Участие в оценке трудозатрат и планировании
  • Участие в presale и discovery-фазах проектов
Требования
  • Опыт в разработке или архитектуре ПО от 5 лет
  • Понимание микросервисной и монолитной архитектуры
  • Опыт проектирования высоконагруженных или distributed-систем
  • Знание принципов проектирования API
  • Умение доносить технические решения до нетехнической аудитории
  • Опыт подготовки технической документации
Будет плюсом
  • Опыт работы в FinTech или enterprise-проектах
  • Знание облачных платформ (AWS, GCP, Yandex Cloud)
  • Опыт с event-driven архитектурой
Условия
  • Полная занятость
  • Возможен удалённый формат работы
